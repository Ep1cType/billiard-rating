Доступ администратора

Чтобы сохранять турниры, нужен токен доступа к GitHub-репозиторию сайта. Он хранится только в этом браузере и никуда, кроме GitHub, не отправляется.

Как получить токен?
  1. Откройте github.com/settings/tokens (Fine-grained tokens).
  2. Нажмите Generate new token.
  3. Задайте название и срок действия (например, 1 год).
  4. В Repository access выберите «Only select repositories» и укажите репозиторий этого сайта.
  5. В Permissions → Repository permissions найдите Contents и выберите Read and write.
  6. Нажмите Generate token и скопируйте его — он показывается только один раз.

Токен даёт доступ только к тому репозиторию, который вы выбрали на шаге 4 — не к всему аккаунту.

Новый турнир
